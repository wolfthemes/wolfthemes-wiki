# FAQ

## Stylesheet is missing or theme installation fails

Be sure to upload only the theme zip file, not the full downloaded package from ThemeForest. If the issue persists, check your [Server Requirements](../general/server-requirements).
[Read more →](../troubleshooting/stylesheet-missing)

## Where can I find my purchase code?

- After purchaseing your theme on [WolfThemes.com](https://wolfthemes.com), you will received by email direclty in your inbox
- In your [ThemeForest Downloads](https://themeforest.net/downloads), click the **Download** button next to your theme and select **License certificate & purchase code (text)**.

## My video background doesn't work on mobile

Video backgrounds are disabled on mobile by default as most devices don't handle them well. You can set a fallback image in the video background options — it will display when the video is disabled.

## 404 error on custom post type pages

Go to **Settings > Permalinks** and click **Save Changes** to flush rewrite rules.
[Read more →](../troubleshooting/404-error)

## Demo content fails to import

Check your [Server Requirements](../general/server-requirements) — particularly `memory_limit`, `max_execution_time` and `upload_max_filesize`. If the one-click import fails, use the [manual import](../getting-started/import-demo-content-manually) instead.
[Read more →](../troubleshooting/issue-importing-demo)

## Do I need to activate bundled plugins?

No. Bundled plugins like WPBakery Page Builder and Slider Revolution work without activation. You can safely ignore any purchase code requests from these plugins.
[Read more →](../getting-started/bundled-plugin-activation)

## My fonts or icons are not displaying correctly

Check that Elementor's default fonts are disabled under **Elementor > Settings > General** and that the CSS Print Method is set to **Internal Embedding** under **Elementor > Settings > Performance**.
[Read more →](../troubleshooting/elementor-settings)

## How do I update my theme?

Use the [Envato Market plugin](https://github.com/envato/wp-envato-market) for automatic updates, or download the latest package from ThemeForest and re-upload manually.
[Read more →](../how-to/themeforest-theme-update)

## My site is slow — how do I speed it up?

Make sure you are on a [reliable host](../general/recommended-web-hosts) and install EWWW Image Optimizer, WP Super Cache and Autoptimize.
[Read more →](../how-to/increase-loading-speed)

## How do I translate my theme?

Use the [Loco Translate](https://wordpress.org/plugins/loco-translate/) plugin to translate directly in your WordPress admin using the `.pot` file included in the theme package.
[Read more →](../how-to/translate-theme)
