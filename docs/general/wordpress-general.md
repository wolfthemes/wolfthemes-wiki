# WordPress General

![WordPress General](/images/wordpress-big-logo.png)

A working version of [WordPress](https://wordpress.org/) must be installed on your server/domain before you can install one of [our themes](https://themeforest.net/user/wolf-themes/portfolio?ref=wolf-themes). If you need help installing WordPress, follow the [WordPress Codex](http://codex.wordpress.org/Installing_WordPress), or watch the Woo Themes [Instructional Video](https://www.youtube.com/watch?v=ftrGQ2dJPJE).

Before using any theme, it is important to understand how native WordPress functions work, and how to establish ownership of your new site.

## Useful WordPress Links

- [WordPress Codex](http://codex.wordpress.org/Installing_WordPress) — General information about WordPress and how to install it on your server.
- [Instructional Video](https://www.youtube.com/watch?v=ftrGQ2dJPJE) — Informative Woo Themes How To video.
- [First Steps With WordPress](http://codex.wordpress.org/First_Steps_With_WordPress) — General information about WordPress.
- [FAQ New To WordPress](http://codex.wordpress.org/FAQ_New_To_WordPress) — The most popular WordPress FAQs.
