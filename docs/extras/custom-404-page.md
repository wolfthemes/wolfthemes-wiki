# Create a Custom 404 Error Page

To set a custom 404 error page, install and activate the [404page – your smart custom 404 error page](https://wordpress.org/plugins/404page/) plugin.

1. Create the page you want to use as your 404 page.
2. Go to **Appearance > 404 Error Page** in your WordPress admin.
3. Select the page you just created as the **"Page to be displayed as 404 page"**.

That's it — all 404 errors will now display the content of your custom page.
