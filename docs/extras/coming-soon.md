# "Coming Soon" or "Maintenance" Mode

To put your website in maintenance mode, install the [Wolf Maintenance](https://plugins.wolfthemes.com/wolf-maintenance/wolf-maintenance.zip) plugin. It is ultra light and simple to use.

Once installed, go to **Tools > Maintenance** in your admin panel and select the page you want to redirect visitors to — for example a "Coming Soon" page.

![Maintenance Mode](/images/maintenance-mode.jpg)

When your website is ready, set the option to **Disabled** to bring your site back online.
