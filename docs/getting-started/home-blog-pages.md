# Home & Blog Pages

By default, when no page is set in **Settings > Reading**, WordPress displays the latest posts as the front page.

To specify a custom front page and blog page:

- To set a **Front page**, go to **Settings > Reading** and select the desired page as "Front page".
- To set a **Blog page**, create a new page with no content and assign it as "Posts page" in the same panel.
