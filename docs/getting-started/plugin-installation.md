# Plugin Installation

![Plugin Installation](/images/plugin-installation.jpg)

When you install or update one of our themes, you will receive a WordPress notification advising you to install and activate the required and recommended plugins. Follow the link provided in the notification and install the plugins.

**You must install all required plugins if you want to import the demo data.**
