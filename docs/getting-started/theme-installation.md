# Theme Installation

If you purchased on [wolfthemes.com](https://wolfthemes.com), the theme zip file is sent directly to your email inbox after checkout — download it from there. If you purchased on ThemeForest, download the package from your [ThemeForest Downloads](https://themeforest.net/downloads) section instead.

## Zip Upload Installation

1. Get the theme zip file (from your wolfthemes.com purchase email, or extracted from the ThemeForest package).
2. In your WordPress admin panel, go to **Appearance > Themes**.
3. Click **Add New** then **Upload Theme** at the top.
4. Upload the **theme zip** file (e.g. `themename.zip`).
5. Once installation is complete, activate your new theme.

## FTP Upload Installation

1. Get the theme zip file (from your wolfthemes.com purchase email, or extracted from the ThemeForest package).
2. Extract the archive.
3. Via your FTP client (FileZilla, Transmit, etc.), upload the theme folder to `wp-content/themes/`.
4. Once the upload is complete, activate your new theme.

For more detailed instructions please refer to the [theme documentation](../general/theme-documentations).
