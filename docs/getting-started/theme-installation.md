# Theme Installation

## Zip Upload Installation

1. Download the theme package from your [ThemeForest Downloads](https://themeforest.net/downloads) section.
2. **Extract the archive** downloaded from ThemeForest.
3. In your WordPress admin panel, go to **Appearance > Themes**.
4. Click **Add New** then **Upload Theme** at the top.
5. Upload the **theme zip** file from your extracted package folder (e.g. `themename.zip`).
6. Once installation is complete, activate your new theme.

## FTP Upload Installation

1. Download the theme package from your [ThemeForest Downloads](https://themeforest.net/downloads) section.
2. **Extract the archive** downloaded from ThemeForest.
3. Via your FTP client (FileZilla, Transmit, etc.), upload the theme folder to `wp-content/themes/`.
4. Once the upload is complete, activate your new theme.

For more detailed instructions please refer to the [theme documentation](../general/theme-documentations).
