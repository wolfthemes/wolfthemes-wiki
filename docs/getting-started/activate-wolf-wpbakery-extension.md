# Activate Wolf WPBakery Page Builder Extension or Wolf Core Plugin

> **ThemeForest purchases only.** If you purchased the theme through wolfthemes.com, the plugin is activated automatically — no action needed.

![Wolf Core Activation](/images/wolf-core-activation-notice.png)

Once the theme and plugins are installed, you have a few days to activate the **Wolf WPBakery Page Builder Extension** or **Wolf Core** plugin to verify your purchase.

Go to **Appearance > About the Theme** and click the **License** tab. Enter your [theme purchase code](http://help.market.envato.com/hc/en-us/articles/202822600-Where-Can-I-Find-my-Purchase-Code-) to activate the plugin.

![Wolf Core License](/images/license-activation.png)

**You don't need to activate anything else.** See [Bundled Premium Plugin Activation](../general/bundled-plugin-activation) for more information.

If your code is correct but activation still fails, please [post a support ticket](https://wolfthemes.ticksy.com).
