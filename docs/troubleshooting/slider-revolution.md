# Slider Revolution Not Starting - (version 6.5+)

There have been changes in Slider Revolution version 6.5 and above.

If you experience any issues, for sliders that have the "Wait for the API start" option checked in the "General" settings, please navigate to the slider settings > CSS/jQuery > Custom JS SR6 tab and copy its content.

![Custom JS SR6 tab](/images/slider-revolution-sr6-tab.png)

Then, paste the copied content into the JS SR7 tab and replace *revstart* with *start*.

![Custom JS SR7 tab](/images/slider-revolution-sr7-tab.png)

Be sure that I will monitor the future Slider Revolution release and release theme updates if needed.
