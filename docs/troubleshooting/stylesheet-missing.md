# Stylesheet is Missing or Theme Installation Fails

A common issue for users new to installing WordPress themes is a "Broken theme and/or stylesheets missing" error when trying to upload or activate a theme.

## The Most Common Cause

**Do not install the full downloaded package (from wolfthemes.com or ThemeForest).** You must extract it first and upload only the theme zip file inside.

See the [Theme Installation](../getting-started/theme-installation) guide for the correct process, and read the [Envato article on this error](https://help.market.envato.com/hc/en-us/articles/202821510-Theme-is-missing-the-style-css-stylesheet-error) for more detail.

## Other Causes

If you are uploading the correct file and still seeing the error, check that your server fulfills the [Server Requirements](../general/server-requirements) — in particular the `upload_max_filesize` and `post_max_size` limits.

The theme is used by thousands of customers on wolfthemes.com and has also been reviewed by the ThemeForest team, so it is tested extensively. If you cannot upload or activate it, the cause is almost always a server configuration issue rather than a problem with the theme itself.
