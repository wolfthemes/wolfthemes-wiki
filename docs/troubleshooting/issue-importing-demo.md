# Issue Importing the Demo Content

Before attempting to import the demo content, make sure your server fulfills the minimum [Server Requirements](../general/server-requirements) and that you have followed the [Import Demo Data](../getting-started/import-demo-data) guide.

## Why Imports Can Fail

Successfully importing demo content can occasionally face challenges due to factors beyond our control, especially varying server configurations. Most of the time the main cause is a [low budget or limited shared hosting server](../general/low-budget-hosts).

Our themes include a third-party plugin to handle the one-click demo import. If you have issues with it, check the [One-Click Demo Import plugin troubleshooting documentation](https://github.com/proteusthemes/one-click-demo-import/blob/master/docs/import-problems.md).

## Manual Import

If the one-click import fails, you can always fall back to the [manual import method](../getting-started/import-demo-content-manually).

## Elementor Themes

If your theme is built for Elementor, you should find the Elementor templates included in the demo package.
